# PokerNow AutoShow

## Purpose
AutoShow is a Chrome extension for pokernow.com intended for use in GTO Illini PokerNow practice sessions.
It is more convenient to analyze play when we can see each player's hole cards and pick out individual mistakes.
AutoShow makes getting the hole cards easier, especially in multitabling sessions where it is easy to miss the
end of a hand and fail to show one's hole cards as a result.

## Installation
You will have to install AutoShow manually.
1. Click the green **Code** button at the top right of this page.
2. Select **Download ZIP**.
3. Extract the downloaded file to a folder on your computer.
4. Open Google Chrome and type `chrome://extensions/` into the search bar (and hit enter).
5. Turn on **Developer mode** using the toggle switch in the top right of the page.
6. Click the new **Load unpacked** button that appears in the top left of the page.
7. A file explorer prompt will appear. Select the unzipped folder (the one which directly contains the `mainfest.json` file).

## Usage
Click the new puzzle piece ifcon in your browser toolbar, in the upper right.
Pin the AutoShow extension, and you can now toggle between Active and Inactive modes for practice sessions and real games.
